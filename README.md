# POO Fighting Game

Jogo de batalhas em Python para a disciplina de POO.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python src/main.py
.venv\Scripts\python -m pytest
```

As teclas disponíveis aparecem na janela. R reinicia e Esc fecha o jogo.
